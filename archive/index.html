Data Analysis & ML

F1 Performance Analytics & Winner Prediction

End-to-End Data Engineering & BI Project

analyzes Formula 1 racing performance from 2018–2021 using a fully cleaned and engineered dataset. It combines data engineering, advanced analytics, tire and pit-stop strategy modeling, driver/team performance profiling, and machine learning to predict future season champions.

📊 1. Dataset & Cleaning

Dataset: Flattened multi-season F1 race dataset (Driver, Constructor, Pit-stops, Lap metrics).

Cleaning Phase 1: Fixed invalid pit times, normalized tire compound naming, standardized columns.

Cleaning Phase 2: Logic validation (stints = pit_stops + 1), fixed final-stint values, calculated aggression metrics.

⚙️ 2. Data Engineering (Star Schema)

Fact Tables: Fact_PitStops (granular), DriverRace (aggregated race level), DriverSeason (aggregated ML ready).

Dimensions: Dim_Driver, Dim_Constructor, Dim_Race, Dim_Season.

Engineered Metrics: Point efficiency, Pit-stop performance gaps, Aggression scores per lap.

🏎️ 3. Analytical Insights

Race-Level: Pit-stop efficiency, Race difficulty scoring, Position gain patterns.

Driver-Level: Consistency metrics, Overtaking behavior, Wet/Dry compound strength.

Team-Level: Tire strategy fingerprints, Reliability markers, Track-specific dominance.

🤖 4. ML Prediction Model

Goal: Predict season champion.

Model: XGBoostClassifier.

Features: Avg finish, aggression score, pit efficiency, constructor performance.

Results: 70–85% accuracy on historical seasons.
